# Fine-tuning the Tier-1 intent classifier

RelayOps fine-tunes a **small open-source instruct model** for intent
classification — the cheap Tier-1 step that lets the router skip the frontier
model on the easy majority. This is deliberately *not* "fine-tuning Claude":
Anthropic's API is text-generation only (no customer fine-tuning of Claude), so
the honest and more impressive claim is:

> I fine-tuned a small open-source intent model (Qwen2.5-1.5B-Instruct) with
> Unsloth/LoRA, and kept Claude/frontier models for Tier-2 reasoning.

## What we fine-tune
- **Model:** `Qwen2.5-1.5B-Instruct` (cheap, fast, strong small classifier).
  Llama-3.2-1B/3B are drop-in alternatives.
- **Method:** LoRA/QLoRA via Unsloth — base weights frozen, small adapters
  trained. Portfolio-friendly and runs on a single modest GPU.
- **Output:** strict JSON, **intent only** — `{"intent": "reset_device"}`.

## Two deliberate honesty/design choices
1. **No risk/route in the model.** The model classifies intent; the deterministic
   access gate + router map intent → route/risk. Policy stays out of weights
   ("facts/policy in weights" is an avoided anti-pattern; routing must be
   inspectable and non-spoofable).
2. **Confidence from token probabilities.** At inference we read the mean
   probability the model assigned to the tokens it emitted — we do *not* bake a
   fabricated `0.91` into the training labels.

## Pipeline
```bash
pip install -e '.[finetune]'                 # GPU recommended
python3 -m src.eval.build_intent_dataset     # -> 2,400 grouped examples
python3 -m src.eval.export_finetune_data     # -> src/eval/data/finetune/{train,val,test}.jsonl
python3 -m src.router.finetune_train         # trains a LoRA adapter -> models/...
RELAYOPS_INTENT_MODEL=models/intent-qwen2.5-1.5b-lora \
  python3 -m src.eval.run_intent_eval        # compares vs keyword + Complement NB
```

Downloaded adapters work too:
```bash
RELAYOPS_INTENT_MODEL=/path/to/intent-lora.zip python3 -m src.eval.run_intent_eval
```
If adapter/base loading fails, add `RELAYOPS_DEBUG=1` for a traceback. To force a
specific base model instead of the adapter's saved base, set
`RELAYOPS_INTENT_BASE_MODEL=Qwen/Qwen2.5-1.5B-Instruct`.

## Dataset format (chat JSONL, one conversation per line)
```json
{"messages":[
  {"role":"system","content":"You are an intent classifier ... Respond with ONLY valid JSON {\"intent\": \"<one_label>\"}."},
  {"role":"user","content":"my internet box is frozen, can you restart it"},
  {"role":"assistant","content":"{\"intent\": \"reset_device\"}"}
]}
```
Generated by `export_finetune_data.py` from the labeled set, split 70/15/15
(stratified per intent). The system prompt is shared with inference
(`finetuned_classifier.SYSTEM_PROMPT`) so training and serving match.

## How it plugs in
`FineTunedIntentClassifier` implements the same `classify(text) -> Classification`
interface as the keyword and Complement-NB classifiers, so the pipeline swaps it
in unchanged:
```python
from src.router.registry import get_classifier
handle_turn("reset my router", auth_token="tok_alice", classifier=get_classifier("finetuned"))
```

## The comparison that matters
The portfolio story is model **selection**, not "I used an LLM". Report all four
on the same held-out + adversarial sets:

| Classifier | Cost | Notes |
|---|---|---|
| keyword baseline | ~0 | brittle on paraphrases / slang |
| Complement NB | ~0 | offline learned baseline; beats keyword on the tail |
| safe calibrated NB | ~0 | v1.2 routing baseline with calibrated confidence + safety overrides |
| fine-tuned Qwen2.5-1.5B | low | trained/evaluated on held-out + legacy adversarial; 100-case rerun pending |
| prompted frontier (Claude) | high | strong zero-shot; the Tier-2 reference |

Current measured on the expanded 2,400-example paraphrase-rich dataset (offline,
with Qwen held-out measured separately): keyword 0.492 → Complement NB 0.932
(5-seed CV). Splits are group-aware so related synthetic paraphrase families do
not leak across train/test. On the v1.2 100-case adversarial/paraphrase set,
keyword is 0.490, Complement NB is 0.660, and safe calibrated NB is 0.880. The
Qwen LoRA measured 0.958 acc / 0.804 macro-F1 on the earlier 24-case adversarial
set; rerun it on the 100-case set before upgrading that claim.
